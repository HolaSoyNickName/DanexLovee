# Contribuir

## Flujo de trabajo

1. Actualiza tu rama base antes de empezar.
2. Trabaja en una rama corta con prefijo `feature/`, `fix/`, `docs/` o `refactor/`.
3. Mantén cada cambio enfocado y vincúlalo con los requisitos DL correspondientes cuando se conozcan.
4. Ejecuta las pruebas y la compilación afectadas.
5. Revisa el diff y no incluyas credenciales, archivos `.env` ni datos privados.
6. Documenta las decisiones que alteren contratos, datos o reglas de negocio.

No se ha configurado un remoto ni una política de merge para este repositorio.

## Convenciones

- JavaScript con módulos ES.
- Frontend React/Vite y backend Express.
- Interfaz y documentación en español.
- Los errores deben ser explícitos; no se deben ocultar con valores por defecto que aparenten éxito.
- La autorización se implementa y verifica en backend, nunca únicamente en la interfaz.
